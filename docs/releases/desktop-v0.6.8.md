# Skillbox v0.6.8 更新说明

本次更新让技能查找更方便，名称复制更顺手，并优化列表与详情交互。

### 查找与整理

- 新增类别筛选，可与搜索、Agent、范围和集合筛选配合使用。
- 新增名称升序、名称降序、最近更新、最近安装和收藏优先排序。
- 新增“未归入集合”入口，快速找到尚未收纳的技能。
- 新增版本差异筛选，集中查看母本与 Agent 副本内容不一致的技能。
- 清除筛选时保留当前排序方式。

类别沿用名称与描述的自动识别规则；时间排序依据已有安装记录，缺少记录的技能排在后面。

### 名称复制与详情

- 悬停列表中的技能名称可一键复制完整名称，详情页标题旁也支持复制。
- 复制成功后短暂显示勾选反馈，复制操作不会打开或关闭详情。
- 再次点击同一技能关闭详情，点击其他技能直接切换。
- 修复详情标题在空间充足时被提前截断的问题；长名称悬停可查看全名。

### 界面优化

- 排序与技能数量、批量选择合并在同一行，列表布局更紧凑。
- “选择”改为带图标和边框的“批量选择”按钮，进入后显示“完成选择”。
- 修复鼠标选择排序后橙色焦点框持续显示的问题，保留键盘操作的焦点提示。
- 优化名称与复制按钮的结构，避免交互控件嵌套。

### 安装提示

若下载的 macOS 安装包未签名或未公证，系统可能阻止首次打开。请仅从本仓库 Release 下载并确认来源，再通过“系统设置 → 隐私与安全性 → 仍要打开”允许运行。未签名应用无法通过 Apple 开发者身份验证，请自行确认信任后安装。
