发布日期：2026 年 9 月 1 日

本次更新完善了项目级 Skill 的识别与展示，并增强了 Agent 独立副本的同步和保护机制。

### Skill 管理

- 项目级 Skill 现在会自动归属对应 Agent；同名的全局 Skill 与项目副本将合并为一条记录。
- 内容不一致的独立副本会在详情中标出差异，可直接同步至母版；关闭 Agent 适配时会保留独立修改。
- 同步前会备份母版与独立副本，并支持母版和项目副本位于不同磁盘。
- 修复分组目录及嵌套项目中的 Skill 未显示或归属错误。

### Agent 支持

- 新增 MiMo Code、iFlow CLI 和 CatPaw 适配。

### 更新体验

- 升级后，后续更新将由用户确认后下载，并显示版本、发布日期、下载进度和更新说明。
- 已是最新版本时不再显示更新内容。

更新不会更改现有 Skill、Agent 适配关系或独立副本。
