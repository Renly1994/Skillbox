# Skillbox v2.0.0 更新通告

这次更新加入了首页总览、MCP 管理、Skill 来源更新和历史版本，也补齐了中文翻译与跨磁盘存储功能。

- **新增首页总览**
  一眼查看技能数量、Agent 覆盖、范围分布、同步冲突和最近动态。

- **Skill 支持关联来源与检查更新**
  可关联 GitHub 仓库或本地目录，支持批量关联、检查全部或选中技能的更新。查看文件差异后，再确认更新。

- **新增历史版本与恢复**
  编辑、更新和恢复时自动保存快照，也可手动保存。支持查看历史正文、比较文件变化，以及恢复整个 Skill 目录。

- **新增中文翻译**
  本地技能与市场详情支持原文、译文切换，中文简介同步显示在列表中。可使用自己的 DeepSeek、OpenAI、Claude 或兼容接口，译文支持本地缓存和 Token 用量统计。

- **新增 MCP 管理**
  统一查看多个 Agent 的 MCP 配置，支持添加、移除、跨 Agent 适配和配置同步。自动检测配置差异，修改前备份，外部配置变化后自动刷新。

- **支持更改 Skill 存储位置**
  可将通用技能库迁移到其他磁盘，保留原路径兼容入口；来源关联、集合、别名、翻译偏好和历史记录随迁移保留。

- **技能库与市场更好用**
  新增显示别名、Agent 覆盖排序，统一管理 Skill 与 MCP 收藏。市场卡片增加简介与分类，并区分“已安装”和“本地同名”，减少误装。

- **扩展 Agent 支持与界面优化**
  新增豆包工作、VS Code（Copilot）的 Skill 识别与适配。优化页面布局、设置弹窗、缓存与加载体验，并修复存储迁移、跨盘同步和 Windows 图标等问题。

- **新增「支持作者」入口**
  支持微信、支付宝自愿打赏。软件功能照常使用，感谢每一份支持。

- **恢复版本更新通告**
  发现新版本时先显示更新内容，点击“立即下载更新”后才下载。修正等待下载时的状态提示，并支持从顶部提示或设置中重新查看通告。

已安装较早的 v2.0.0 时，请从本页重新下载安装包并安装；同版本不会触发自动更新。现有 Skill、Agent 适配关系和本地数据保留。

欢迎更新体验，遇到问题或有建议，欢迎反馈。
