发布日期：2026 年 9 月 2 日

本次更新重点改善 Skill 市场安装和本地 Skill 扫描体验。

### Skill 市场

- 安装时优先只下载所选 Skill，不再默认拉取整个仓库，速度更快、占用更少。
- 没有安装 Git 的设备也能直接安装市场 Skill；网络受限时会自动切换其他下载方式。
- 新增下载与安装进度。关闭详情或离开市场页面后，任务仍会在后台继续，重新进入后可继续查看进度和失败原因。
- 下载过程中退出应用会给出提示，避免意外中断安装。
- 修复同一仓库包含多个 Skill 时，可能装错内容或错误显示“已安装”的问题。

### Skill 扫描

- Agent 全局目录现在支持递归扫描，可发现多层分组中的 Skill。
- 修复 Pi 等部分 Agent 的全局 Skill 目录无法正确识别的问题，并兼容旧版目录。
- 自定义扫描目录不再限制层级，可递归发现深层目录、嵌套项目和项目分组中的 Skill。
- 深层项目仍会保留对应 Agent 归属；多个 Junction 指向同一 Skill 时只显示一条记录。
- 扫描命中 Skill 后不会继续进入其支持文件目录，并会跳过常见依赖和构建产物目录。

更新不会更改现有 Skill、Agent 适配关系或独立副本。
