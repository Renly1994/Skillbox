# Skillbox v0.6.7 更新说明

本次更新集中优化 Skill 扫描、同名内容识别、Agent 适配与删除体验，让 Skillbox 在目录较多、项目较复杂的情况下也能保持准确、稳定和安全。

### 扫描更准确

- 优化全局、项目和自定义目录的扫描边界，不再把依赖、构建产物、虚拟环境、隐藏工具目录或嵌套仓库中的素材误识别为已安装 Skill。
- 自定义目录仍支持任意层级的标准 Agent 项目目录、深层独立 Skill，以及用户明确添加的 Skill 仓库。
- 扫描不会跟随 Junction 或符号链接跳出用户添加的目录范围。
- 修复部分 Agent 全局目录识别不完整、项目目录被误算为全局适配的问题。
- 统一 Skill 总数、全局、项目、自定义及各 Agent 的统计与筛选逻辑。
- 右上角“扫描目录”调整为更清晰的“添加目录”。

### 同名 Skill 展示更合理

- 全局母版及其 Agent、项目或自定义位置会合并为一个 Skill，不再重复显示。
- 同一项目中分布在多个 Agent 目录的同名 Skill 会合并展示。
- 不同项目中的同名 Skill 会比较完整内容：内容一致时合并并保留全部项目归属，内容不同时分别显示，避免误合并。
- 自定义目录与全局 Skill 同名且内容一致时合并，内容不同时继续独立显示。
- 修复同名 Skill 合并后项目数量、Agent 图标和详情归属不一致的问题。

### Agent 适配更可靠

- 项目目录中的 Skill 只表示项目归属，不再被误判为 Agent 的全局适配。
- 修复详情开关、批量操作和 Agent 筛选页面中取消适配后仍显示已适配的问题。
- 同一 Agent 同时存在新旧全局目录时，取消适配会完整处理全部有效入口。
- 直接使用通用 Skill 目录的 Agent 不再重复创建或显示多余适配。
- 适配时如果 Agent 目录已有同名实体副本，会先比较并妥善保留，避免直接覆盖用户修改。

### 删除更清晰、更安全

- 统一详情页、批量选择及 Agent 筛选页面中的删除和取消适配逻辑。
- 删除确认窗口只展示“全局 Skill、项目 Skill、自定义 Skill”等直观范围，不再罗列容易引起误解的内部路径。
- 只想让某个 Agent 停止使用时，可直接关闭对应 Agent 的适配开关，不会删除 Skill 文件。
- 删除 Skill 时按扫描到的真实位置精确处理：快捷入口只解除链接，实体文件夹进入系统回收站。
- 同名但内容或来源不同的 Skill 不会被连带删除；删除失败时会保留未完成项并明确提示。
- 删除后会同步清理失效的收藏、合集和安装记录，列表与统计立即刷新。
- 加强本地及远程删除的路径校验，拒绝删除 Skill 根目录或授权范围之外的位置。

### 稳定性改进

- 修复适配、取消适配、删除或文件快速变化后，旧缓存数据可能导致页面空白的问题。
- 优化扫描刷新和旧版本数据兼容，减少重复条目、过期状态及统计不同步。

安装更新本身不会删除、移动或修改现有 Skill。只有用户明确执行删除操作时，实体 Skill 文件夹才会进入系统回收站。
