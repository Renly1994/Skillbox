发布日期：2026 年 9 月 2 日

本次更新修复 v0.6.5 扩展自定义目录递归扫描后出现的越界收录与重复显示问题。

### 自定义目录扫描

- 添加工作区上层目录时，不再把嵌套 Git 仓库中的 Skill 素材或研究仓库内容当作已安装 Skill。
- 不再进入虚拟环境、依赖目录、构建产物及隐藏工具目录。
- 通用递归扫描不再跟随 Junction 或符号链接跳出用户添加的目录边界。
- 仍支持任意层级的标准 Agent 项目目录、深层独立 Skill，以及用户明确添加的 Skill 仓库。

### 同名 Skill

- 修复全局母版与自定义扫描副本同名时显示两行的问题。
- 同一项目内分布在多个 Agent 目录的同名 Skill 聚合为一行。
- 不同项目中的同名 Skill 会比较完整目录内容：内容完全一致时聚合并保留全部项目归属，任一有效文件不同时分别显示。
- 修复 Agent 适配、取消适配或文件变化后的快速刷新可能导致页面白屏的问题。

更新后应用会重新扫描并清理旧缓存中的误收录条目，不会删除或移动磁盘上的任何文件。
